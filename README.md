# Artists — a jobslop plugin

ArtStation's job board for art, animation and games, plus your portfolio links in the profile (filled in on applications).

## What it adds

- **Job boards:** ArtStation (Art, animation & games jobs worldwide)
- **Profile fields** (the Chrome extension fills them in on application forms): ArtStation profile, Behance profile, Showreel / demo reel link, Specialism (e.g. 3D environment art, concept art), Software (Blender, Maya, Photoshop…)
- **Its own words in:** da, es, nl

## Install

It comes with jobslop — switch it on in **Settings → Plugins**.

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-artists` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
